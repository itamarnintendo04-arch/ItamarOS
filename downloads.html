Unverified developer preview: Debug-signed test APK, not an official store release. Build and file checks do not establish malware safety. Use only on a spare test device; do not bypass Play Protect, antivirus warnings or TV security restrictions. This installs an app, not an operating system.

Android TV: white screen or no Install prompt?
  1. A white page in Downloader is not the Android installer. Open Downloader's Files section and check whether ItamarOS-Android-1.3.0-debug.apk was downloaded.
  2. If the file is missing, use the direct download link above in a compatible browser on another device, then transfer the downloaded APK to the TV using a USB drive and open it with the TV's file manager. Do not install a web page, ZIP, or HTML file.
  3. Check the TV's internal available storage. Even though the APK is about 12 MB, Android needs additional working space to install it. Having only around 120 MB free may prevent installation. Do not delete important apps or data without a backup.
  4. If Android shows an installation or security warning, follow the device's normal security restrictions. Do not turn off Play Protect or bypass a warning to force the installation.
  5. If the app installs but opens to a white screen, that is a different issue: record the Android version, whether the home screen ever appears, and any error message for debugging.

iPhone · iPad · Personal signing only

📱 ItamarOS iOS 1.6 — developer IPA

Up to five local Apple account profiles may be remembered in the iPhone app, but only one may be selected at a time. These profiles do not authenticate a developer signing session.

Sign right here on ItamarOS: our local WebAssembly signer accepts an IPA, your own .p12 certificate, and an Apple provisioning profile. The signing process runs on your device in the browser and downloads a signed IPA. No ItamarOS server receives your private key, IPA, certificate password or Apple ID credentials. An Apple ID alone does not create a valid certificate or guarantee installation.

🔏 Sign IPA on ItamarOS (in your browser)

A valid Apple-issued certificate and provisioning profile are required. Signing is separate from device installation. The iOS device must still accept your provisioning and permissions. For signing with a free Apple ID without exported certificate files, use a supported personal developer tool instead.

How do I install the real ItamarOS?

Only after a verified, tested ISO is released: back up files; check hardware compatibility; verify the ISO checksum; first test the Live ISO in a virtual machine; then use the graphical Calamares installation wizard on a supported PC. Manually review all partition choices: replacing or resizing partitions can erase data.

Phone, tablet and TV devices require separately built firmware/boot support. The current native system source targets amd64 desktop computers only.
