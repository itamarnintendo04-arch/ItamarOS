Native apps · Version 1.1 source projects

ItamarOS for iPhone, iPad, Apple TV, Android & Android TV

Native applications are being built in SwiftUI (Apple) and Kotlin/Jetpack Compose (Android), not as WebViews. They include local games, settings and native media tools. Android TV can request a user-selected USB backup folder, but moving the app itself depends on the TV manufacturer and Android system settings.

No signed IPA, APK, App Store/TestFlight or Google Play installation package has been released yet. The linked GitHub folders are developer source code, not download-and-install buttons.

How do I install the real ItamarOS?

Only after a verified, tested ISO is released: back up files; check hardware compatibility; verify the ISO checksum; first test the Live ISO in a virtual machine; then use the graphical Calamares installation wizard on a supported PC. Manually review all partition choices: replacing or resizing partitions can erase data.

Phone, tablet and TV devices require separately built firmware/boot support. The current native system source targets amd64 desktop computers only.

Read safe installation guidance
ItamarOS is a development project. Do not overwrite an existing operating system without a verified compatible release and backup.
