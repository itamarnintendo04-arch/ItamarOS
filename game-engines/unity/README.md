# ItamarOS Unity games

Unity 6 (2022.3+ for the basic scripts) projects live here. The original Swift/SpriteKit versions remain untouched as migration references.

- ArenaRush: top-down arena shooter controller, enemies, health, pickups, bullets and match state.
- SkyboundIsles: 2D platform/adventure character controller and collectibles.
- ItamarOSGames: continuous Snake game using orthogonal movement with smooth interpolation.

These are **source foundations**, not yet complete Unity editor projects: they need Unity scenes, sprites, prefabs, UI canvases, input bindings and iOS export setup. Open each directory in a Unity project, add the scripts to the corresponding GameObjects and assign prefab references. Unity licensing and Apple Xcode signing/build requirements still apply. No IPA is produced by these files alone.
